数学概念小课堂

期望值: 所有可能结果乘以发生概率的总和

方差: 衡量结果的波动程度，方差越大越不稳定

安全路径期望值 = 2×1.0 = 2.0

风险路径1期望值 = 0×0.5 + 4×0.5 = 2.0

风险路径2期望值 = 1×0.7 + 5×0.3 = 2.2

游戏帮助

欢迎参加迷宫概率挑战！这是一个帮助小学生理解概率和决策的数学游戏。

如何玩：

  1. 从起点开始，每次掷骰子前进
  2. 当到达分叉路口（紫色格子）时，选择你想走的路径
  3. 当到达方向选择点（粉色/蓝色/绿色格子）时，选择移动方向：
    • 粉色：向左/向右
    • 蓝色：向右/向下
    • 绿色：向下/向左/向右（新增）
  4. 不同路径有不同概率获得宝石：
    • 安全路径（黄色）：经过自动获得2颗宝石
    • 风险路径（红色）：经过时需要停留并做出选择，有概率获得宝石
  5. 记录你的选择结果，看看哪条路平均获得宝石最多！

学习目标：

  • 理解概率的基本概念
  • 学习期望值的计算方法
  • 了解方差如何衡量风险
  • 培养基于数据的决策能力
